AW NEON PLAYER - پروژه اندروید

روش ساخت APK بدون نصب Android Studio روی لپ‌تاپ:
1) فایل ZIP را از حالت فشرده خارج کن.
2) در GitHub یک repository جدید بساز (مثلاً AW-Neon-Player).
3) فایل‌های داخل این پوشه را در repository آپلود کن؛ خود پوشه‌ی اصلی را داخل یک پوشه‌ی اضافی نگذار.
4) از تب Actions، گردش‌کار "Build AW NEON PLAYER APK" را اجرا کن (اگر خودکار شروع نشد، Run workflow را بزن).
5) پس از پایان موفق، وارد اجرای workflow شو و از بخش Artifacts فایل AW-NEON-PLAYER-APK را دانلود کن.
6) ZIP آرتیفکت را در گوشی باز کن؛ فایل app-debug.apk را نصب کن. ممکن است اندروید اجازه‌ی نصب از آن منبع را بخواهد.

نکته:
- این نسخه debug APK برای نصب و آزمایش شخصی است، نه انتشار رسمی در فروشگاه.
- فایل‌های موسیقی از داخل خود برنامه انتخاب می‌شوند و در این برنامه روی سرور آپلود نمی‌شوند.
- برای نصب APK، فقط از فایل ساخته‌شده توسط workflow خودت استفاده کن.
